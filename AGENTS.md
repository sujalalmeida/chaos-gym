# Development

- Keep changes small and focused. Commit and push each working increment.
- Run relevant tests and lint before committing. Keep the working tree clean after a milestone.
- Write concise documentation and commit messages in the project's voice.
- Derive reports and interface values from execution data; do not add fabricated metrics.
- Prove the refund workflow before expanding the engine or dashboard.
- Keep examples deterministic, local, and free of provider credentials.
- Check committed effects independently of attempted calls and injected faults.
